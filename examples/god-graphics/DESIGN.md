# Existing composition design

Preserve the original 1920×1080 explanatory compositions when using them as a reference. Each `index.html` declares its duration and contains its layout, typography, palette and paused GSAP timeline. Navy/near-black backgrounds, teal highlights and restrained violet accents organize the existing designs; labels and diagrams carry the narrative.

Before adapting a composition, identify the visual hierarchy and choose new copy that fits it. Read the bundled HyperFrames and GSAP skills, keep seekable timelines and deterministic states, and update duration metadata when changing timing. These are full-frame explainer scenes, not transparent overlays.
